# Simple Self-Hosted CI/CD Deployment Simulation

This example Python script simulates a basic automated deployment process, akin to what a self-hosted CI/CD (Continuous Integration/Continuous Deployment) tool would perform. It demonstrates the automation aspect of developer tools for infrastructure, creating dummy build artifacts and then deploying them to a target directory. This highlights how open-source, self-hosted solutions can provide control and flexibility over deployment workflows.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Observe the created `build_artifacts` and `production_deployments` directories.
